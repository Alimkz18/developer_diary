# Developer Diary

A public log of what I'm learning and building, kept by Alim Zhainakov.

I'm an Information Systems Cybersecurity student at Collin College. This repo is where I write down progress, mistakes and what I'd do differently, so that a year from now I can see the path and not just the result.

## Areas

- **Infrastructure:** Proxmox home lab, Linux administration, networking (Cisco, VLANs, services)
- **Security:** CompTIA Security+ prep, Google Cybersecurity certificate coursework, home lab hardening
- **Code:** Python (Telegram bots, automation on the Claude API), C# / .NET, web apps
- **Game development:** Unity, Blender, Substance Painter — a longer-term interest

## Structure

```
daily/      short notes on what was done and what broke
weekly/     review of the week: what worked, what didn't, next steps
monthly/    outcomes and goals for the next month
```
